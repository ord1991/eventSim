# Prophesee EVK4 (IMX636) Event Camera Control & Recording Application

מערכת שליטה והקלטה גרפית (GUI) בעלת עיצוב כהה ומודרני למצלמת אירועים של חברת **Prophesee** (חיישן **EVK4 / IMX636**), הכתובה בפייתון תוך שימוש ב-SDK הסטנדרטי **Metavision**.

האפליקציה תומכת באופן מלא במצלמה פיזית המחוברת ב-USB, ומציגה מנגנון נפילה לאחור (Fallback) חכם המפעיל **סימולטור אירועים דינמי** כאשר ה-SDK או המצלמה אינם מזוהים. זה מאפשר פיתוח, בדיקה והדגמה מלאה של הממשק גם ללא חומרה מחוברת.

---

## פתרון בעיית ה-SDK בסביבות וירטואליות (Venv / PyCharm) 💡

מאחר שספריית ה-Metavision מותקנת על המחשב שלך כחלק מהחבילה הכללית של Prophesee ולא דרך `pip install` פשוט מהאינטרנט, הסביבה הוירטואלית של פייתון (venv) שנוצרה בפרויקט מבודדת אותה כברירת מחדל.

פיתחנו באפליקציה מנגנון **Auto-Bootstrap** חכם במיוחד המזהה אוטומטית שאתה רץ בתוך venv בוינדוס, קורא את קובץ ה-`pyvenv.cfg`, מחלץ את נתיב הפייתון הראשי של המחשב שבו מותקן ה-SDK, ומזריק ישירות את תיקיות ה-`site-packages` הכלליות ואת ה-DLLs הדרושים (`add_dll_directory`) לתוך הריצה!

בנוסף, הוספנו אפשרות בממשק להפנות אותו ישירות לתיקיית ה-SDK/DLL שלך דרך כפתור **בחר...** וטעינה ידנית.

### דרך פשוטה לוודא שהסביבה הוירטואלית שלך ב-PyCharm ניגשת ל-SDK:
אם עדיין המערכת אומרת שה-SDK חסר, מומלץ לאפשר לסביבה הוירטואלית שלך לגשת לחבילות המערכת המותקנות מקומית (System Site-Packages):
1. בתוך **PyCharm**, כנס להגדרות: `File -> Settings -> Project -> Python Interpreter`.
2. לחץ על גלגל השיניים שליד ה-Interpreter ובחר `Show All...`.
3. בחר את ה-Interpreter שלך, ולחץ על כפתור העריכה (עיפרון) או וודא שמסומנת התיבה **Inherit global site-packages** (או צור venv חדש עם פקודה זו):
   ```bash
   python -m venv .venv --system-site-packages
   ```
זה יפתור את הבעיה באופן מיידי ולצמתיות!

## תכונות מרכזיות (Key Features)

### 1. תצוגת וידאו בזמן אמת (Live View Window)
- שחזור והצגה של זרם האירועים בזמן אמת כווידאו דו-מימדי (אירועי עלייה ON בירוק, אירועי ירידה OFF באדום).
- **שליטה על זמן האקומולציה (Accumulation Time)**: סליידר ייעודי המאפשר שינוי של חלון צבירת האירועים במילישניות בזמן אמת (בין 1ms ל-100ms).

### 2. גרף קצב אירועים (Real-time Event Rate Plot)
- חלון ייעודי המציג את קצב האירועים (באלפי אירועים לשנייה - `kEvt/sec`) על גבי ציר הזמן.
- הגרף ממומש באמצעות Matplotlib ומציג היסטוריה מתגלגלת של 20 השניות האחרונות.

### 3. לוח פרמטרי המצלמה (Camera Biases & Advanced Controls)
- **שליטה על Biases של EVK4 / IMX636**: סליידרים מדויקים לשינוי פרמטרי החיישן לפי הטווחים הרשמיים של היצרן (מנוהלים כ-Offsets יחסיים סביב 0):
  - `bias_diff`: רמת ייחוס של פלט פוטורספטור.
  - `bias_diff_on`: סף רגישות קונטרסט לאירועי עלייה (ON).
  - `bias_diff_off`: סף רגישות קונטרסט לאירועי ירידה (OFF).
  - `bias_fo`: תדר חיתוך של פילטר מעביר נמוכים (Low-pass filter).
  - `bias_hpf`: תדר חיתוך של פילטר מעביר גבוהים (High-pass filter).
  - `bias_refr`: משך הזמן המת של הפיקסל לאחר יצירת אירוע (Refractory period).
- **בקרת קצב אירועים (ERC - Event Rate Controller)**: אפשרות להפעלה וקביעת מגבלת קצב האירועים המקסימלי לשנייה כדי לחסוך רוחב פס.
- **פילטר רעשים דיגיטלי (Event Trail Filter)**: אפשרות להפעלת מסנן רעש דיגיטלי וקביעת סף השהייה במיקרו-שניות.

### 4. שמירה וטעינה של הגדרות (JSON Configuration)
- אפשרות לשמירה (Export) וטעינה (Import) של כל ערכי ה-Biases לקובץ JSON התואם לפורמט הרשמי של Metavision SDK.

### 5. הקלטת אירועים (RAW Recording)
- אפשרות לבחירת מיקום ושם קובץ ההקלטה בפורמט הרשמי `.raw` של Prophesee באמצעות תיבת דו-שיח גרפית.
- הפעלת והפסקת ההקלטה בלחיצת כפתור אחת.
- **סטטיסטיקות הקלטה בזמן אמת**: משך זמן ההקלטה, גודל הקובץ השמור ב-MB, סה"כ אירועים שהוקלטו וקצב נוכחי.

### 6. ריבוי תהליכים (Multi-threading Support)
- קריאת הנתונים מהמצלמה ומה-Slicer של Metavision מתבצעת ב-Worker Thread נפרד מאחורי הקלעים, מה שמונע את קפיאת הממשק הגרפי (Tkinter) ושומר על זריזות ותגובתיות מלאה של ה-GUI.

## דרישות מערכת והתקנה (Requirements & Installation)

כדי להריץ את האפליקציה, יש לוודא שמותקנות חבילות הפייתון הבאות:

```bash
pip install numpy opencv-python matplotlib pillow
```

*הערה*: במידה וברצונך להתחבר למצלמה פיזית, ודא כי ה-**Metavision SDK** מותקן על מחשבך וניתן לייבא את `metavision_sdk_stream` ו-`metavision_hal`. במידה ולא, המערכת תזהה זאת ותעבור אוטומטית למצב סימולטור.

## הרצת התוכנית (How to Run)

להפעלת תוכנת השליטה וההקלטה, הרץ את הפקודה הבאה מהטרמינל:

```bash
python3 event_recorder_app.py
```

הפרויקט כולל סוויטת בדיקות מקיפה המאמתת את נכונות הסימולטור, עדכוני הפרמטרים ופורמט האירועים:
